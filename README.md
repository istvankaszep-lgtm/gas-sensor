# gas-sensor
I'm making this gas sensor, if it dedect's gas, the buzzer will go off and it will print a warning sign on the lcd desplay. it also print' s the temperature.

# how to uploade the code.
To upload the code (firmware) you need to download arduino ide, then download this three librarys from the IDE library:
1. LiquidCrystal_I2C (Frank de Brabander)
2. OneWire (Jim Studt / Paul Stoffregen)
3. DallasTemperature (Miles Burton)

4. then uploade the firmware from this repo, and uploade the code to the arduino nano.

5. # part's:
6. 1. lcd screen
   2. gas sensor
   3. arduino nano
   4. Temperature sensor
   5. buzzer
   6. rgb led
   7. usb_c port
